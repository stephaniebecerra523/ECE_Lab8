## Summary
In this lab, we learned how multiplexers and demultiplexers work. We used a multiplexer to select one of four different inputs and a demultiplexer to send that data to one of four outputs. We also learned how to use select bits, enable signals, and ternary operators to control where the data goes.

## Lab Questions

### In plain English describe the function and use of a multiplexer.
- A multiplexer takes multiple inputs and selects one to send to a single output. It uses select bits to decide which input to use. Multiplexers are useful when multiple devices need to share the same connection.

### In plain English describe the function and use of a demultiplexer.
- A demultiplexer takes one input and sends it to one of several outputs based on the select bits. This can be used when data needs to be sent to different devices using the same connection.

### What other uses might these circuits have? (Think Shannon’s)
- Multiplexers and demultiplexers can be used in processors, memory, and communication systems. Shannon’s theorem also shows how multiplexers can create Boolean logic functions.
